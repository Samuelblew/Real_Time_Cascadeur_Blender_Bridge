# Origem do código

Este projeto contém adaptações de **Blender_Cascadeur_RT**, de **Carlos Barreto / Antigravity**:

- Repositório: https://github.com/carlosedubarreto/Blender_Cascadeur_RT
- Commit-base: `b48c582d4471ab8df78b682687ecd7728b20469f`

Os créditos originais presentes no código foram preservados. As adaptações incluem
o modo Same Rig, transferências confirmadas por frame, sincronização esparsa de
chaves, observação de edições no Blender e correções após exclusões de chaves.

O commit-base consultado não contém um arquivo LICENSE. Este repositório não
atribui uma licença adicional ao material de terceiros; consulte o projeto de
origem e seus autores para condições de uso e redistribuição.
